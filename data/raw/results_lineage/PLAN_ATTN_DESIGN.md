## 0. 一句话 + 北极星 + 结合原理

**北极星（用户定调，作为本批与论文的架构叙事）**：低维潜空间循环 = **向量化算子 RNN**（向量态 × 离散算子步 × 装置接地；**解题步骤序列本身就是该 RNN 的任务目标**）；gen30 要做的 = **把它升级为向量化算子 Transformer** —— 在循环骨架上加**步级自注意力**的关系轴。**升级 = 加轴，不是换本体**（见 §0.2 不变式）。

在**不碰体、不碰帧布局、不碰链监督语义、不动 R0 本体**的前提下，于链头 `heads()` 的**步级决策向量 `x`** 上挂一个 ≤0.51M 参数的**步级多头注意力残差**：query = 当前步决策隐态，key/value = **全部前步的（算子, 实参, 装置真算 device_state）三元组嵌入**（P1）；算子分量由 `lat_tab` 静态行经**上下文门控调制**（P2）；末步读出作为计划摘要并入渲染头输入（P4-lite，开关默认开）。

**结合原理（高维计划序列注意力 × 低维潜空间循环 think）**：
- **循环链 = 时间轴骨架**：离散符号步、`allow` 合法门、`WALK_BUDGET` 上限、装置接地、逐算子可审计 —— R0 本体，**一字不动**。
- **步级注意力 = 骨架内的关系轴**：每步对**全部前步**三元组做一次软加权重读（谁能回看谁、权重多少，**逐头**可导出）。
- 二者**按构造互补**：注意力**不替代**循环，只在骨架的每一步**增厚上下文**——循环给"离散 + 可审计 + 接地"，注意力给"长程步骤关系 + 步位概念"。经典对位 = **注意力增强 RNN（Bahdanau 系）**；我们的"RNN"是**算子级策略循环**（每步输出是符号算子 + 槽绑定，离散性比词级 RNN 更强、与注意力互补更纯）。
- **低维原则（用户设计哲学红线）**：计划层保持"低维身份"（0.50M 对 135M 底座 ≈ 0.37%）——循环 = 骨架、注意力 = 骨架内软关系，不把注意力堆成第二个 transformer。**多头分工**（≥2 头）+ **步位偏置**（相对步距）是 RNN→Transformer 的标配件，一并落地。

### 1.2 张量与帧位（逐位登记）

| 符号 | 来源 | 含义 |
|---|---|---|
| `H` | `heads(H, bc, C, dev, allow)` 入参 | 链段隐态 `(B, Lc, HID)`，HID=576 |

| query | `LN_q(x_t)` → `W_q` | 当前步隐态 |
| key/value 第 j 步算子分量 | `lat_tab[op_j]` ⊙ `(1+g_j)` | `op_j = R.labels[j]`（该决策点**监督目标算子**；非 fail 帧处 = `desc` K_OP 帧 arg，测试断言） |
| key/value 第 j 步实参分量 | `R.bsl[j·24:(j+1)·24]` | 24 槽绑定值（= `bc.slots`；装置侧代理口径沿用 gen26 登记） |
| key/value 第 j 步 device_state 分量 | `R.res[res_idx_j]`（8 维） | **装置每步真算的 res 帧**，经 `desc[feat_pos[j]-2]` 的 K_RES arg 取；K_PSZ(fail 帧) 或 None ⇒ 全零 |
| 帧位常量 | `op 帧 = R.feat_pos[j]-4` · `res 帧 = R.feat_pos[j]-2` | 顺序 `(M_OP)(K_OP)(M_RES)(K_RES)(M_TAGFR)(K_PST)` 定长 ⇒ 偏移固定；**逐行 `desc` 布局断言**（首访校验并缓存），违规计数入报告 |
| 有效性 | `key_ok[j] = j < len(R.feat_pos)` | END 步（无 op/res 帧）不作 key |
| 因果 | `attn_ok[t,j] = (行内) ∧ (j < t) ∧ key_ok[j]` | **严格前步**；j ≥ t 一律 −inf；行间块对角（无跨样本注意力） |
| P4-lite | `o_T` = 每行**最后一个有效步**的读出 → `W_ps` | 注入渲染头输入（非体输入，见 §4） |

## 2. 前向公式（P1 多头 + P2 + P4-lite；低维 64+32+64→128，2 头 × 64）

```
记 d2 = 2·HID = 1152, N = B·Talloc, S = NSLOT = 24, n_h = 2, d_h = 64, d_a = n_h·d_h = 128
   d_g = 64, d_arg = 32, d_dev = 64, n_b = 6 (相对步距桶)

# --- P2: 上下文门控动态算子嵌入 ---
c_t   = LN_q(x_t)                                    # (N,1152)
g_t   = tanh(W_g·c_t + b_g)                          # (N,64) ∈(-1,1) 有界乘性门
op~_t = lat_tab[op_t] ⊙ (1 + g_t)                    # (N,64)   同算子 × 不同上下文 ⇒ 不同表示

# --- P1: 三元组 key/value, 多头分工 (≥2 头) ---
A_t   = W_ap·( Σ_{v≥0} E_arg[v+1] / max(1,#valid) )                     # (N,32) 实参池化
D_t   = W_d2·GELU(W_d1·res_t + b_d1) + b_d2                             # (N,64) 装置状态
e_t   = LN_e([ op~_t ; A_t ; D_t ])                                     # (N,160)
头 0 (状态依赖):  q0_t = W_q0·c_t ;  k0_t = W_k0·e_t + W_kd·D_t ;  v0_t = W_v0·e_t + W_vd·D_t
头 1 (算子相容):  q1_t = W_q1·c_t ;  k1_t = W_k1·op~_t        ;  v1_t = W_v1·op~_t

# --- 逐头注意力 (严格因果 + 步位偏置) ---
d_tj  = t - j (行内, ≥1);  b_tj = bucket(d) = d-1 (d≤4) | 4 (5≤d≤7) | 5 (d≥8)
s^h_tj = q^h_t·k^h_j / sqrt(d_h) + pos_bias[h, b_tj] + m_tj ,  m_tj = 0 若 attn_ok 否则 −inf
a^h_t· = softmax_j(s^h_t·) · 1[∃ 合法 key]                               # 无合法 key ⇒ 全零行
o_t   = [ o^0_t ; o^1_t ] ,  o^h_t = Σ_j a^h_tj·v^h_j                   # (N,128)

# --- 残差融合 (P1/P2 注入; W_out 零初始化) ---
x_t ← x_t + W_out·LN_A(o_t)          (W_out=0 at init ⇒ 起点逐位等价)

# --- P4-lite: 计划摘要 (零初始化) ---
summ  = W_ps·o_T        (T = 每行最后一个有效步)
渲染头输入: lm_head( H[:,Lc:,:] + summ.unsqueeze(1) )
```

- **多头分工（补充令锐化 A）**：头 0 = **状态依赖头**（全三元组 + device 专属投影，回答"当前状态需要什么算子"）；头 1 = **算子组合相容性头**（仅 `op~`，回答"哪个算子与**前步算子**相容"）——两条关系**结构解耦**（T13 断言：device 扰动下头 1 逐位不变、头 0 变化）。头数入差异清单（§6）。
- **步位偏置（补充令锐化 B）**：每头 6 桶**相对步距** bias，**零初始化**（起点 = 无偏置 ⇒ 不破坏 PA-EQ3），近步先验由训练习得；训练后逐桶值 + `recency_gap` 入报告（T14 验证"注入近步先验 ⇒ 近步权重升、远步降"）。
- **融合点（补充令 ①）**：`step_head` 与 slot 头读**融合态** `x`（`zi = se + x`，与基线同构）；`allow` 门 / END / `WALK_BUDGET` 原样。
- **登记偏离（§8-1）**：补充令写"`LayerNorm(h_t + W_o·A_t)`"；**后融合 LN 会破坏 Δ≡0 起点逐位等价**（LN(x)≠x）⇒ 违反配对干净性硬约束。归一化功能位**等价改置**为：query 侧 `LN_q` + **读出侧 `LN_A`**（注意力输出先归一化再进残差），残差结构保留。
- **参数表（P1+P2 = 427,212 = 0.427M；+P4-lite 74,304 ⇒ 合计 501,516 = 0.502M ≤ 2M 预算的 25%）**：
  `LN_q` 2,304 · `W_q×(2 头)` 147,584 · `W_g` 73,792 · `E_arg(353×32)` 11,296 · `W_ap` 1,056 · `W_k0/W_v0(e→64)` 20,608 · `W_k1/W_v1(op→64)` 8,320 · `dev1/dev2` 4,736 · `W_kd/W_vd` 8,320 · `pos_bias(2×6)` 12 · `LN_e(160)` 320 · `LN_A(128)` 256 · `W_out` 148,608 · `W_ps` 74,304。
  **P1-nostate 臂**（套内消融）= **405,836**（状态依赖头去 device：`e_dim=96`，无 dev MLP 与专属投影）。
- 复杂度 `O(B·n_h·T²·d_h)`，T ≤ MAXFR=25 ⇒ 相对 30 层体前向可忽略；**本模块不含任何随机层**（无 dropout）。

## 3. 初始化（配对干净性的机制）

| 参数 | 初始化 | 目的/证据 |
|---|---|---|
| `W_out.weight/bias` | **全零** | 起点 `delta ≡ 0` ⇒ 与对照臂**逐位等价**（PA-EQ2/3） |
| `W_g.weight/bias` | **全零** | 起点 `g=0 ⇒ op~_t = lat_tab[op_t]` **逐位**=静态行（P2 从静态表出发），PA-EQ4 |
| `W_ps.weight/bias` | **全零** | P4-lite 起点 = 渲染头输入逐位不变（PA-EQ6） |
| `pos_bias(2×6)` | **全零** | 步位偏置起点 = 无偏置（不引入先验，PA-EQ3 不受影响） |
| `W_q/W_k*/W_v*/W_kd/W_vd/W_ap/W_d*` | Xavier-uniform（私有生成器） | 常规 |
| `E_arg` | `N(0,0.02²)`（私有生成器） | 常规；0 行 = 无实参占位，强制零 |
| `LN_*` | weight=1, bias=0 | PyTorch 默认 |
| 其余 bias | 0 | 常规 |
| **RNG 隔离** | 构造前后 `get/set_rng_state()` 包裹 + 新参数用**私有 `torch.Generator`（种子 = `seed*1000003+30`）** | 不消耗全局 RNG ⇒ 同 seed 下基线非新参数**逐位不变**（PA-EQ1） |

## 5. 可解释性：注意力权重导出接口（证据件；补充令 ⑥）

- `PlanStepAttention.forward` 在 `capture=True` 时缓存 `attn (H,N,N)`（detach，不参与反向）；`HybridModelAttn.attn_snapshot()` 输出**逐头** `{row, T, stepsym, n_heads, steps[{t,op,res_idx,w_prefix_heads,w_prefix_head0/1,w_prefix}], edges[[t,j,w^0..w^{H-1}]], attn_sum[]}`；`bias_report()` 输出 `{bucket_edges, per_head 逐桶偏置, recency_gap_head}` → **"哪些步被当前步回看、权重多少"逐头可读**（补充令 ⑥ 的论文级证据件）。
- 考段对 **≥20 例**考卷行导出 `out/GEN30_ATTN_SAMPLES.jsonl`：每例给出**步骤关系图** —— 当前步回看了哪些前步、权重多少（`edges` 阈值 ≥0.05）、序列和 `Σ_j a_tj = 1`（或 0 = 无前步）。
- **符号可审计性**：`stepsym` 是走链的符号算子名序列本身；注意力只改 logits，不改序列表示 ⇒ 链仍逐算子可审计、可回放、可交付 Lean 终审。

## 8. 边界、登记偏离与不做的部分（禁静默）

1. **登记偏离（融合点 LN）**：补充令①的"后融合 LN"改为 **query 侧 `LN_q` + 读出侧 `LN_A`**，理由 = 后融合 LN 破坏 Δ≡0 起点逐位等价（配对干净性硬约束优先）。残差融合结构、`W_o` 零初始化、`step_head/slot 头读融合态`三条均保留不变。
2. **缺口③（链对渲染单向因果）主体不实现**：仅 P4-lite 一路零初始化摘要（开关，两态读数）；渲染段的体输入/掩码/CE 一字不动。
3. **P2 限注意力侧表示**：不做"体侧 op 帧嵌入重写"（需二次体前向 ⇒ 成本 ×2，且破坏单卡时间预算与零初始化等价）⇒ 登记为下一批候选。
4. **`A_BRIDGE_V1` 不入本批**（沿 gen26 令）；**Test 243 封存**；**考卷侧触面 = 0**（导出件只落 gen30/**）。
5. **装载次序**：PA 模块**必须**在 `load_init_ccp()` 之后挂载（`v32lib.load_init` 对 state_dict 未知键有断言）——已写入模块头注与集成步序。
